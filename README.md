# My Project

## Описание

В этом проекте реализованы четыре функции:

1. **sum_divisible_by_3_or_5(n)**  
   Возвращает сумму чисел от 1 до n, которые делятся на 3 или 5.

2. **check_email(email)**  
   Проверяет, корректен ли email-адрес (простая проверка с использованием RegEx).

3. **count_number_in_list(lst, x)**  
   Считает, сколько раз число x встречается в списке lst.

4. **calculate_area(width, height)**  
   Возвращает площадь прямоугольника (width * height).

5. Теперь проект поддерживает **считывание транзакций** из CSV и Excel (XLSX) файлов!

6. Для работы с CSV/Excel используется `pandas`.

7. Тесты в `tests/test_data_readers.py` показывают использование `mock/patch` для имитации чтения файлов.

## Новая функциональность

Теперь проект поддерживает чтение финансовых транзакций не только из JSON-файлов, но и из:

- **CSV**: функция `read_transactions_from_csv(filepath: str)`
- **XLSX (Excel)**: функция `read_transactions_from_excel(filepath: str)`

Смотрите модуль `src/data_readers.py`.

## Новая функциональность

- **Поиск транзакций** по описанию (регулярные выражения, `re`) – функция `search_transactions_by_description`.
- **Подсчёт** количества операций по категориям (`collections.Counter`) – функция `count_operations_by_category`.
- **Главная функция** `main()` в модуле `main.py` – предоставляет интерфейс для чтения данных (JSON/CSV/XLSX) и дальнейшей фильтрации, сортировки, поиска, вывода результата.
